# Дизассемблирование (этап 2)

## Разбор инструкций

- `movl $0, -4(%rbp)`: переменная sum (по адресу -4) = 0 (аккумулятор).
- `movl $1, -8(%rbp)`: переменная i (по адресу -8) = 1 (счетчик).
- `jmp .L2`: переход к проверке условия цикла.
- `.L3`: тело цикла. Значение i загружается в `%eax`, прибавляется к sum,
  затем i увеличивается на 1.
- `.L2`: `cmpl $10, -8(%rbp)` сравнивает i с 10, `jle .L3` (jump if less or
  equal) возвращает на начало тела, пока i <= 10.
- `movl -4(%rbp), %eax`: результат (sum) помещается в `%eax`, то есть
  возвращается из функции.

## Эквивалентный код на Python

```python
def sum_to_10():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

## Результат
Функция считает сумму чисел от 1 до 10 и возвращает 55.
